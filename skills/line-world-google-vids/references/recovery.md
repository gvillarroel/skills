# Recovery and evidence

- Account or login: keep drafts and assets. Use the authorized account's normal
  login route. Let the user handle credentials, CAPTCHA or required approval
  when the current computer-use policy requires it. Do not extract sessions.
- Feature or quota unavailable: record the exact visible message and preserve
  the project. Try an already available supported voice or normal editor path.
  Do not subscribe, buy credits or claim a fallback voice came from Vids.
- UI labels changed: inspect current controls, menus, selected scene and saved
  state. Use screenshots for a contenteditable region absent from the AX tree.
  Reobserve after actions; change tactics rather than repeating a stale click.
- Control missing in a diff: request a fresh full AX tree. Derive indices only
  from that state; never reuse indices from an earlier successful call.
- File upload: foreground and verify the intended project tab before opening
  Upload. Inspect the next state if a dialog appears late. In an observed native
  Open dialog, use File name keyboard focus if owned-dialog indices fail. See
  the one-step recommendations in [UI workflow](ui-workflow.md).
- Timing mismatch: keep the source clip and voice. Verify whether video
  insertion extended the scene, whether a trimmed out-point is too early, or
  whether the wrong scene owns the audio. Recompile after measured corrections.
- Export: confirm the whole project was exported, not a single clip or GIF.
  Check the actual file path, bytes, video/audio streams and full decode.
  If only a cloud project exists, call it a saved project, not a downloaded MP4.
- Fresh Drive export missing from connector search: after one focused search,
  inspect the authorized Drive UI and obtain its actual file ID. Use known-ID
  metadata rather than repeated searches. An empty Copy link clipboard needs
  another observation; it is not a link. Follow [verified delivery](delivery.md).

Keep a small project-owned journal containing scene IDs, scripts, observed
duration, selected voice, media file, export status and sanitized evidence.
Avoid storing unrelated browser history, credentials, raw account menus or
private cookies in screenshots/receipts. Reversible project edits needed to
complete the user's request do not require an extra approval step.
