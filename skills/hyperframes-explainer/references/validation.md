# Validation Gates

Run preflight, browser audit, native HyperFrames `check`, encode and media checks
in that order. Repair the responsible brief/model/layout layer when a gate fails.
Do not hide a real finding by weakening a scale, omitting a required quantity or
declaring its overlap intentional. Expected preflight findings are JSON with
`ok:false` and exit zero, including malformed brief JSON with a line/column
diagnosis; infrastructure failures are nonzero. Repair browser findings before
the native check. Invoke generated scripts by their project paths from the workspace;
the wrapper resolves movie output paths before entering the project directory.

## Semantic and interactive checks

Sample event start, ramp midpoint, end and the final hold. Compare the resolved
state with the source facts/formulas. Check independent values and declared
equalities. A rate change must alter the post-event accumulation slope; an
allocation change must not change a conserved total.

The browser audit compares snapshots against pure `stateAt`, follows actual SVG
bindings, changes preview inputs, reconstructs earlier times and checks bounded
marks, paint and text contrast. Inspect its `ok`, findings and actual screenshot.
Confirm that changing one control propagates to every dependent view and leaves
unrelated quantities untouched. One master clock without shared semantics is
insufficient.

The input API is a real preview interaction, not a prerecorded hover animation.
Controls remain outside the filmed stage. Mark/report a custom extension's audit
coverage; the native audit cannot prove unregistered graphics are correct.

## Readability and economy

Before encoding, inspect the asset plan and composed still. Confirm that each
selected skill supplies the intended explanatory capability, every imported shape
is represented in the audit, and source hashes match the retained editable assets.
Review silhouette, moving part, actual port contact, and the mapping from physical
state to geometry. Compare against a generic-box baseline when improving an
existing film; fewer words alone do not constitute better visual explanation.

Watch muted playback or inspect exact movie frames. Identify the initiating
action, its direction, at least two distinct consequences, and anything conserved.
If these are unclear, improve the representations before adding text.

Inspect event states at full resolution and at intended playback size. Direct
labels must be attached to their marks; values need units; essential marks need
contrast. Avoid unexplained hue changes, clipped or occluded text, overlapping
views, axis rescaling and decorative motion that competes with the event.

No title is the default. A sparse film can still fail if its model is false,
its scales misleading, or its synchronized changes unrelated. Record manual
semantic review separately from mechanical pass/fail.

## Media

Verify width/height, exact frame rate, duration within one frame, expected frame
count, H.264/yuv420p for MP4 and optional AAC audio. Fully decode the delivered
file with FFmpeg and create a contact sheet from that same file. Inspect event
midpoints and final-state readability. With audio, check that its actual placement
and duration match the picture; do not add a score or narration unless useful or
requested.

Keep JSON reports, screenshots, contact sheets and videos in project artifacts.
The acceptance fixture is for maintainers; normal runtime use does not read it.
