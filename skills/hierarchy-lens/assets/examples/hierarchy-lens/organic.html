Reading the pixels

Center → root. Each outward band → one reporting generation. A sector and the sectors beyond it → one branch. Color → the selected attribute.

Pixels compose each record's region; one pixel is not one person. Angular span reflects branch headcount. Pixel area is not comparable across rings. Empty regions mean that a reporting branch has ended.

Gray checkerboard → no observation. The darkest heat color → an observed zero. Zoom and selection keep the global color thresholds fixed.
