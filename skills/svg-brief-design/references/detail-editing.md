# Editing the base into the requested drawing

Use a scaffold for repeated geometry and spend attention on the choices that
identify the requested object. A finished vector should not advertise which
default generator produced it.

## Structure before ornament

Assign a role to each major group: silhouette, opening, connection, annotation,
or decoration. Keep structure and details in separate groups so their relative
weight and visibility can be inspected. Mentally hide the details: the requested
subject and arrangement should still be recognizable.

For a custom bilateral subject, draw fresh landmarks for the central axis,
outer contour, joint positions and interior openings. Mirror geometry that
really corresponds using a group transform, then introduce intentional
asymmetry. Do not substitute a polygon badge for the subject's silhouette.

For organic work, use a small number of continuous curves and taper features
toward their ends. Vary lengths and spacing through a controlled progression.
Avoid independent random displacement of every point; it destroys rhythm.

## Connectors and diagrams

Calculate endpoints from the same anchors as the objects they connect. Shorten
an arrow shaft or move a port when its head covers an object label. For a
curved connector, orient its arrowhead along the final tangent. Check incoming
and outgoing roles separately from whether a line is horizontal or vertical.

A decorative scientific appearance does not establish a physical relation.
Use a real function or construction for any explicit mathematical claim.
If the brief only asks for a vintage scientific motif, keep unspecified labels
and quantities modest and do not claim scientific validation.

## Text and dense panels

Keep supplied words as editable text unless the user requests legitimate
outlining. Plan the longest actual string first; reserve a clear region for it.
Use fewer, larger textual roles before adding rules or decorative marks.
Do not replace requested information with little lines resembling writing.
Inspect rendered glyphs: XML text presence alone does not prove readability.

Treat bars and square codes according to the request. A machine-readable code
needs a payload, a real encoding and a decoder check. If the user explicitly
wants a decorative code-like motif, describe it accordingly. Do not quietly
add fake functional data to a general label.

## Openings, margins and final edits

Design an opening as missing material, not a white patch. Compound paths with
`fill-rule="evenodd"` or self-contained masks can preserve transparent holes.
Check the final raster alpha or display over a colored surface when the hole's
transparency is uncertain. Touching black masses can erase narrow channels.

Judge the occupied shape's width and height before judging the canvas ratio.
Extra canvas width cannot turn a compact emblem into a genuinely horizontal
strip. Leave enough margin for strokes, joins and rotated details. An edge
warning from the preview helper requires inspection; intentional bleed is
different from an accidentally clipped feature.

Render after the last geometry or text edit. Inspect a thumbnail for silhouette
and an intended-size view for labels, gaps and joins. Keep the editable recipe
for parameter revisions, or the directly edited SVG when it has become the
authoritative drawing. Avoid unrelated polish that weakens the brief.
