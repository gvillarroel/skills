# Author, review, refine

For a task needing independent scrutiny, use delegate_tasks in pipeline mode
with three stages: author drafts, reviewer checks concrete claims and omissions,
refiner returns the supported final analysis. Supply complete task facts and an
output contract in each stage. The pipeline passes bounded output from all prior stages;
it does not provide shared memory or the full parent transcript.

Review the returned stages before answering. Preserve unresolved objections and
source citations. A failed stage means the chain is incomplete; report it rather
than presenting an unreviewed result as accepted. Use at most one additional
repair chain within the configured child budget. Do not grant a child filesystem,
shell, posting or evolution rights through a prompt. All outputs are private
analysis unless a separate authorized integration performs an external action.
