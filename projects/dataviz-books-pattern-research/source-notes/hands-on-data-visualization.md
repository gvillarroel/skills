## Assimilated Guidance

- Choose among table, chart, map, and interactive embed according to the user task, not by defaulting to a chart.
- Use a map only when geographic level, boundary, distance, or location changes the interpretation.
- Declare class breaks, denominators, source, geometry source, date, and credit when color encodes a mapped measure.
- Keep interactive values available through a non-hover fallback for small screens.
- Treat source, credits, units, captions, and access to underlying values as part of the publishable pattern contract.
