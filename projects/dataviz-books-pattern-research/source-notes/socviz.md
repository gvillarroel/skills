## Assimilated Guidance

- Start with the audience and communicative task before selecting the chart.
- Make data preparation and summary state explicit when plotting already summarized values.
- Use title, subtitle, caption, and source text as part of the explanation, not decorative extras.
- Use facets and reference distributions when comparison across groups needs stable context.
- Consider map alternatives when geography is not the core question.
