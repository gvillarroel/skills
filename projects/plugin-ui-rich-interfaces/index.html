What the critique changed

Keep one analysis view active.

The overview helps cross-view comparison, but makes this task longer to scan. The focused layout preserves selection while switching Dependencies, Metrics and Service table.

Reduce scope on a narrow surface.

The mobile view shows the selected service and direct neighbors, with an explicit way to browse the full list. It preserves direction and readable labels.

Make charts explain their values.

Units, UTC hours, the 250 ms objective, a shared scale and an exact-values table accompany the line. Narrow layouts recompute ticks instead of shrinking text.

Verify the visible result and the contract.

Tests cover late cancellation, retained data, keyboard focus and refused expansion. Pixel review caught a blank iframe capture despite passing interactions; the capture was repaired.
