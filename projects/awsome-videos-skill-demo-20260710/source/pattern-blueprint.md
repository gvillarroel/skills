# Pattern Blueprint: Why Vector Databases Feel Fast

Selected format: compressed explainer (explicit format request)
Runtime: 80 seconds (80 seconds)

## Video Type
- compressed explainer: Claim, definition, mechanism, concrete example, tradeoff or callback.

## Pattern Sets
- Visual sources: logo/title anchor, UI proof, diagram proof, code proof, meme/editorial insert
- Animation atoms: punch-in zoom, highlight sweep, stack build, diagram trace
- Transitions: hard cut, punch-in, match cut, snap zoom
- Audio roles: background bed, hit/stinger, whoosh/tick, riser, final tail
- Script moves: claim hook, one-sentence context, contrast pair, reset line, warning beat, callback, technical joke
