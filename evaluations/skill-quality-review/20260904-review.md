# Skill guidance review — 2026-09-04

Reviewed the backlog, entry-point sizes, reference layout, and repository gates
for all 19 canonical skills at baseline `35163ae1`. The working tree was clean
at the start. This was a repository-wide structural review followed by focused
changes to two skills; it was not a fresh behavioral evaluation of all 19.

## Changes and measured scope

| Skill | Entry-point bytes before | After | Reduction |
| --- | ---: | ---: | ---: |
| `compose-synchronized-svg` | 35,889 | 10,594 | 70.5% |
| `asciinema-real-command-video` | 16,164 | 8,866 | 45.1% |

Measurements count UTF-8 bytes after normalizing line endings. The complete
19-skill inventory and exact method are in [20260904-metrics.json](20260904-metrics.json).
These are instruction-footprint measurements, not observed token, latency, or
output-quality improvements from model runs.

The SVG entry point previously repeated detailed renderer, state, runtime,
review, and failure-handling contracts. Its normally required semantic
reference also loaded the compiled-plan schema and complete runtime API.
The revised entry point routes creation, artifact review, custom fragments,
and runtime integration separately. The existing compact authoring reference
now links to two optional extension contracts. Exact preflight semantics,
compiler/composer commands, honest quantitative encodings, failure routing,
browser gates, and review requirements remain available.

The terminal entry point repeated lifecycle and review mechanics, while the
shared plan reference included all interactive-TUI fields even for a simple
direct-argv plan. Interactive plan fields and detailed lifecycle/review
guidance now have focused references. The entry point explicitly respects
plan-only requests by stopping after plan validation. Real process and input
provenance, one attempt per requested recording, per-video ownership, actual
TUI timing, presentation-boundary disclosure, and validation remain required.

Five extraction checks confirm that the moved compiled contract, runtime API,
interactive schema, terminal lifecycle, and visual-review paragraphs retain
their original text. Skill descriptions, interface metadata, runtime scripts,
templates, and published examples did not change.

For a complete compact-SVG generation/review route, the four guidance files
shrank from 109,341 to 66,886 normalized bytes (38.8%). The direct-argv plan
route's entry point plus shared schema shrank from 29,176 to 15,624 bytes
(46.4%). These static totals exclude templates and tool output; they are not
measured agent read surfaces.

## Repository validator improvement

`validate-pattern-ids.py` used recursive enumeration followed by filtering.
That still walked large `node_modules`, `dist`, and ignored evaluation-run
trees. It now prunes excluded directories before descent and preserves
authored examples and durable evaluation sources. Directory symlinks remain
unfollowed.

The initial and final reports are identical: 1,222 canonical item IDs, 512
explicit canonical IDs, 815 declarations, maximum ID length 46, and no IDs
above the review threshold. The optimized command measured 2.690 seconds in
this checkout. The earlier invocation was not timed end-to-end, so no speedup
ratio is claimed. The five new regression cases cover retained source scope,
forbidden-subtree traversal, invalid authored-example IDs, missing roots, and
directory symlinks; all five ran and passed.
