# Efficient-delivery acceptance criteria

Frozen before forward testing, October 31, 2026, America/New_York (runs may
have November 1 UTC timestamps). This is a narrow guidance/catalog revision;
keep the preceding composition cohort and source hashes separate.

Contract: one strict isolated run and independent artifact pass. Naturalistic:
three fresh isolated runs, require at least two joint strict/artifact passes.
Use Spark first. An observed pre-tool account rejection permits the existing
per-run Sol 6.1/medium exception without changing thresholds or global settings.

The contract must create both exact artifacts, run the exact checker command,
pass the source check with at least two checked official URLs, and choose an
appropriate low-setup Pi interaction with explicit inputs, cancel safety,
mode distinctions and direct deterministic actions. It must distinguish the
OpenUI agent skill/docs MCP connection from a host renderer. Arbitrary UI
injection or a model turn/server for every small selection fails acceptance.

Naturalistic artifacts must cover all seven named surfaces separately:
ChatGPT, Claude Desktop Chat, Codex desktop, Codex CLI, Pi TUI, Pi RPC and
Claude Code. Reuse domain/actions/state and small adapters where useful;
distinguish web MCP Apps, native/TUI and optional owned clients. Account for
the existing React library, predefined versus generated composition, renderer
and action requirements, and the later spatial task without replacing the
initial product scope. Do not invent a universal manifest, renderer or sidebar.

Keep identity/authority, cancel/retry/stale replies and noninteractive output
usable. Distinguish direct actions, host opening turns and intentional model
work. Efficiency measures must reflect setup, interaction and maintenance
costs without fabricated performance numbers. Native/bridge/browser/host and
proposed/source evidence must remain distinct. Include concrete checks,
styling ownership and proportionate H1-H10 consideration.

Independently validate JSON schema and route uniqueness, inspect full Markdown
and JSON semantics/consistency, exact outputs, read surfaces, actual model,
tool errors and payload integrity. Do not grade by exact phrasing. Missing
outputs, false execution/compatibility claims, incorrect host routes or a
major state/interaction omission fail the artifact. Plans are not executed
host acceptance. No browser screenshots are required for this prose change.
