# Visual asset composition review

Date: 2026-09-27. Baseline commit: `bd10b36c`.

## Changes

The review inventoried 26 skill bundles and measured 23 published entry pages
or hierarchy modes at 1440 × 1000 and 390 × 844. It changed excessive page
spacing and specific renderer defects while preserving native artwork and
requested output dimensions. The previous Mermaid/D3/Three.js node and
palette changes remain in place.

| Owner | Composition change |
| --- | --- |
| D3 | Compact landing page and gallery cards; individual Expand/Fit views for dense SVGs; logo preview before controls on mobile; natural 3:2 preview aspect; smaller desktop controls and 44px touch controls; compact texture catalog. |
| ECharts animated SVG | Compact card chrome and individual reading views; retain SVG transforms and transformed text origins in normal and reduced motion. |
| Mermaid | Reduce oversized gallery hero, methodology and card padding; remove excessive preview minimum heights; retain the native diagram viewBox. |
| PlantUML | Native root padding 6 in both themes; neutral CS1 highlights; regenerate 56 published assets with PlantUML 1.2026.6; resolve local command launchers through PATH. |
| Procedural SVG | Compact hero/cards and a native disclosure for the eleven technique families; retain all 66 SVGs and their motion envelopes. |
| Three.js | Remove forced card-header height, reduce surrounding spacing, retain full scene canvas and touch controls. |
| UsefulCharts | Compact the example page header and cards; preserve authored poster geometry. |
| Vectorize art and world maps | Reduce gallery hero/figure padding while retaining source artwork bounds. |
| Video | Fit the 1280 × 720 preview to the browser; preserve exact 1280 × 720 capture mode. |

The D3 studio route now points directly to its standalone builder. It checks
runtime colors in the rendered SVG; a static HTML source cannot prove the
colors of marks created by JavaScript. A placeholder title/description also
makes the initial SVG accessible before initialization.

comparisons use the same local 1.2026.6 renderer for both themes. Published
PlantUML files previously used Kroki; their fresh local renders may also differ

The mobile logo preview now ends at about 565px, before the controls begin at
577px. All controls measured in the changed D3, ECharts, Mermaid, PlantUML,
procedural and Three.js galleries reach 44px on coarse pointers.

## Preserved contracts and coverage limits

- Technical logos: all 1,960 normalized originals pass their source/hash and
  256 × 256 / 16-unit-padding contract. Their brand clear space is intentional.
- Slidev ECharts: 36 slides and 129 click states, zero findings.
- Slidev Anime.js: 30 slides and 93 click states, zero findings.
- Hierarchy Lens: all four entry/mode pages have no horizontal overflow or
  runtime errors at either viewport. Its compact hierarchy cells remain intact.
- Synchronized SVG compositions retain their authored canvas and shared state.
- SVG-to-GIF, Manim, dithering and pixel-art converters retain input/output
  dimensions and caller-selected crop rules; a catalog padding change does not
  authorize cropping content during conversion.
- SVG illustration and poster artwork retain intentional negative space.
- Pricing, evaluation-dataset, batch-decision, simulation-data and terminal
  recording skills have no shared chart-card padding surface to change here.

The browser inventory is automated coverage plus selected manual screenshots,
not an exhaustive visual judgment of every asset or animation frame. D3 and
ECharts overview thumbnails still contain small text; the added native reading
views provide access to larger labels. Slide navigation and untouched hierarchy
controls were not included in the changed-gallery touch-size assertion.

## Deterministic evidence

- 46 page/viewport combinations: zero document overflow, JavaScript errors or
  broken images. The audit loads offscreen lazy images before checking them;
  unloaded images in the initial scan were not missing assets.
- ECharts: 43 charts and 1,916 candidate marks compared with their static
  geometry in normal and reduced motion; maximum measured difference 0.002px.
  Non-rendering SVG definitions and empty paths are excluded from positional
  comparison, and the reference is frozen with native animations disabled.
- 1,436 reading-view checks: 225 D3 cards × three styles × two widths, plus
  43 ECharts cards × two widths. Expand, Fit, keyboard focus and page containment pass.
- D3 logo gallery: all 90 compositions, 40 textures, text bounds, palette
  variants and replay controls pass the existing mobile browser validator.
  The texture gallery separately passes all 40 patterns and 80 labels.
- All eleven video concepts fit the mobile viewport, and capture retains
  1280 × 720.
- PlantUML: both 29-fixture coverage reports pass; each publishes 28 assets,
  with Chronology explicitly expected-unavailable. Nineteen coverage/CLI tests pass.
- Procedural gallery deterministic `--check`: 66 patterns, no missing,
  changed or extra managed files.
- ECharts existing gallery verification and two static-validator tests pass.

The default Python Playwright browser revision was absent on this machine.
The project wrapper reruns the unchanged D3 browser assertions using installed
Edge. This is an environment adaptation, not removal of an assertion.

## Isolated validation

See [the preregistered protocol](protocol-20260927.md), [case definitions](cases.json),
and the [durable results](summary-20260927.json). Raw attempts remain under
`evaluations/runs/assets-*`.
The model exception is GPT-5.6 Luna because the same-session Spark request was
rejected by the provider before execution. Every selected run uses strict JSON,
exact outputs, runtime-only payloads, and immutable skill resources.

Initial failures exposed a missing D3 studio route, a static/dynamic colorset
validation mismatch, and Windows CLI resolution. They led to bundle fixes and
fresh cohorts. PlantUML's validator also rejected valid neutral-only CS1
activities; it now accepts the palette's grays while retaining the rejection
of an unthemed black/white result. Procedural catalog guidance now routes to
its deterministic managed-file check and distinguishes XML namespaces from
remote dependencies. A contract attempt combined the required command with a copy
step and failed exact-command enforcement. Another used an unrequested `/tmp`
export; it was excluded and replaced by an explicit workspace-relative export
contract. Earlier prompt fences were corrected to the shell syntax recognized
by the harness. Every original attempt remains in the evidence inventory.

All sixteen case gates pass. The selected 32 runs contain 30 strict harness
successes and 32 independently passing visual artifacts. D3 has two retained
trace failures: an unnecessary `/tmp` read and a static HTML check for colors
created at runtime. Its repeated-case results meet the preregistered two-of-three
threshold. The other three final skill cohorts pass all eight strict runs each.

| Skill | Contract | Naturalistic | Boundary | Generalization | Final cohort |
| --- | ---: | ---: | ---: | ---: | --- |
| D3 | 1/1 | 2/3 | 1/1 | 2/3 | d |
| ECharts animated SVG | 1/1 | 3/3 | 1/1 | 3/3 | b contract; a other cases |
| PlantUML | 1/1 | 3/3 | 1/1 | 3/3 | f |
| Procedural SVG | 1/1 | 3/3 | 1/1 | 3/3 | g |

The full evidence inventory retains 91 attempts: 52 harness successes and 39
harness failures, including superseded cohorts. One earlier harness success
was independently excluded because its optional SVG export used `/tmp`.
Successful final traces read the skill and focused references, plus their own
outputs; none reads a sibling bundle or an acceptance gallery.

Repository validation, pattern IDs, skill independence, payload checks and
the fourteen harness tests pass against an isolated copy of the staged
source. The local Pages build and unified-format check pass, and the changed
local skill installations match their canonical sources. Only this review's
explicit files are staged; unrelated local work remains outside the commit.
