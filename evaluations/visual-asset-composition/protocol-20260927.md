# Visual asset composition validation

Date: 2026-09-27. Scope: published catalog composition and four changed runtime
bundles (D3, ECharts animated SVG, PlantUML, procedural SVG gallery).

## Frozen acceptance cases

`cases.json` records the required outputs; the corresponding prompts live in
`evaluations/pi-prompts/assets-*.md`. Each skill has one command contract,
three independent naturalistic attempts, one boundary case, and three
generalization attempts. All use fresh runtime-only workspaces, strict JSON,
exact outputs, immutable skill payloads, and disabled ambient discovery.
Require the contract and boundary to pass, plus at least two of three runs
for each repeated case. Preserve and classify every unsuccessful attempt.

Model exception: `openai-codex/gpt-5.6-luna`, medium reasoning. The same-session
Spark attempt was rejected by the provider before any tool call; the retained
run is documented in `evaluations/mermaid/compact-composition-20260927.md`.
PlantUML is available as a normal local CLI on PATH. No tested agent receives
repository paths, previous outputs, or access to the acceptance galleries.

## Independent artifact review

- D3: open each studio at desktop and mobile widths; require a visible live
  preview before controls on mobile, unchanged native aspect, responsive page,
  usable touch controls, requested branding, and no browser errors.
- ECharts: compare every rendered mark against the supplied static SVG at the
  final frame and with reduced motion. Require preserved labels and transforms,
  no browser errors, and a passing bundled static/animated validator.
- PlantUML: verify the requested source, SVG and report; require a valid SVG,
  correct palette, retained authored padding when specified, readable text,
  and source/renderer consistency.
- Procedural SVG: require a complete standalone catalog, native family
  disclosure, responsive layout, preserved SVG dimensions and pattern IDs,
  usable controls, and a clean generated manifest. Check mobile and desktop.

## Catalog checks

Measure all available published entry pages and hierarchy modes at 1440px and
390px. The catalog scan is automated coverage; selected screenshots receive
manual inspection. It is not an exhaustive visual review of every frame of
every asset. Fixed slide and video capture dimensions, authored logo padding,
and intentional artwork whitespace remain part of their output contracts.

Run the Slidev quality audit over all slide/click states. Compare PlantUML
native padding on ordinary activity, mindmap, sequence, class and rectangle
cases, including an authored override. Verify all dense D3/ECharts reading
controls and ECharts transformed geometry in the browser. Regenerate published
PlantUML assets with the frozen 1.2026.6 renderer and check coverage reports.
