# Preserve supplied quantitative geometry

Use the loaded skill's small static bar-chart template as supplied input.
Copy it to exactly `deliverables/chart.static.svg`, animate it with the
bundled bar profile into `deliverables/chart.animated.svg`, and validate the
pair into `deliverables/chart-validation.json`. Preserve every supplied mark,
label and coordinate. Render/inspect the result and record actual findings
in exactly `deliverables/layout-review.md`.

Treat `skills/echarts-animated-svg/` as read-only. Write all generated files
outside it. Do not read acceptance examples or other skills, and do not
publish anything. Use normal local tools.
