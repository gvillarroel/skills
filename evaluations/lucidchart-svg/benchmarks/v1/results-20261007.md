valid events, zero tool errors, independent artifact checks, an acceptable read

public development cases measure repeatability on these tasks; they are not an

## Retained failures and verifier correction

The original [SVG oracle](validate_svg_cases.py) compared graph `text_color`
strings case-sensitively even though its native color checks already allowed
equivalent RGB spelling. It rejected `#17334D` versus `#17334d` and equivalent
colors in six geometry/relations trials. This is a **validator-design error**.
The [R1 manifest](verifier-revisions/r1/correction-manifest.json) freezes a distinct verifier
whose only artifact-assertion change applies the existing color equivalence
function to that field. Independent review checked the one-line diff.

R1 regrades only those six original workspaces. Before/after file hashes cover
the complete copied payload and all outputs; they remain identical. Original
reports, manifest and cohort remain untouched. The correction brings all six
artifact checks to pass, but the three relations narrative failures remain
failed. The machine-readable archive retains original and corrected component
verdicts, every required artifact hash, trace/report identities and unchanged
manual decisions.

The real agent failures are:

- **Relations 1–3:** notes cite raw gold marker dimensions 8×8 and blue dimensions
  10×6 without accounting for omitted `markerUnits`, whose SVG default is
  `strokeWidth`, as specified by the [SVG marker coordinate units](https://www.w3.org/TR/SVG2/painting.html#MarkerElement). With source stroke widths 2 and 3, the marker viewports are
  **16×16 and 30×18 source pixels**. The prompt explicitly asks for rendered
  size. Disclosing generic native glyph/size loss does not complete that source
  interpretation. Native arrow-class, topology and style artifacts pass.
- **Semantic 1–3:** each agent invokes
  `native_catalog.py --type line`. `line` is not a supported shape-catalog type,
  so the command exits with a tool error. All final artifacts pass the independent
  semantic oracle (542, 550 and 542 checks), but later recovery does not remove
  the strict zero-error failure.
- **Generated 3:** an agent-authored verification command reads
  `report['local_validation']`, causing a `KeyError`; the actual field is
  `report['native_graph']['local_validation']`. Its final artifacts pass all
  186 independent checks. The failed attempt remains in the trace and denominator.

Asset 2 has a minor nonblocking wording error calling the clipped rectangle and
two paths “three paths.” Its exact source/copy bytes, inspection inventory and
material editability/rendering limitations are correct. That observation is
retained in its direct review rather than converted into a hidden grading rule.

Follow-up development priorities are an explicit shape-versus-connector catalog
boundary, evidence-based report-field inspection before assertions, and marker
units/viewport interpretation in source fidelity reports. Any promoted skill
change needs a new subject digest and separately labeled forward cohort. This
benchmark retains the evaluated published payload and records those priorities.
