## Authorized change and scope

The user now permits guides and original scripts informed by general properties
of the purchased SVG collection. Copying the original artwork, paths, distinctive
contours or encoded assets remains prohibited. This is a complete-bundle change,
so the installed `harbor-population-search` workflow is used instead of the
`harbor-evolve-skill` engine's SKILL.md-only mutation surface.

The candidate adds a standard-library JSON-to-SVG generator, a pinned renderer,
focused recipe and detail-editing guides, and deterministic tests. The generator
offers radial blades, projected spherical grids, illustrative oscillations,
connected stage flows, text panels, pinnate fronds, a blank canvas, and boxed
composition. A base is explicitly provisional: the agent must adapt the brief,
replace defaults, build original details, and review a render.

Both candidate and original baseline run with `openai-codex/gpt-6-luna`, medium
reasoning, Pi 0.84.2, SSE, and the same read/write/bash tools and installed Python
renderer dependencies. Historical writing-only scores are not pooled with this
condition. The original verifier remains separate and unchanged.
