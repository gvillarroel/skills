# SVG Brief Design: guidance-only development study

Status: **experimental / validating; study closed without promotion** on 2026-09-25. The first guide improved the six-case mean slightly, but did not reach the gain declared before inference. Two subsequent candidates have unavailable fitness because of provider transport errors. No private gate ran.

The user requested a skill in this repository, added to Pi with `openai-codex/gpt-6-luna`, and evolved against the SVG baseline. The user explicitly excluded purchased SVGs and artwork reconstructions from the skill. The [canonical skill](../../skills/svg-brief-design/SKILL.md) and local `.agents/skills/svg-brief-design/` installation contain only three text files: `SKILL.md`, `references/svg-mechanics.md`, and `agents/openai.yaml`.

## Visual review and evolution

The [rendered comparison](../runs/svg-brief-design-20260925-r2/search/development/generation-000/review/comparison.jpg) shows ground truth, fresh baseline, and first guide side by side. Rendering used the pinned Linux verifier image, its original renderer, and its fonts. The image was visually inspected; no live browser verification is claimed.

The first guide teaches composition before ornament, consistent stroke hierarchy, deliberate empty areas, editable vector construction, and honest review when only a writing tool is available. It improved the HUD and label proxy, but the label still used pseudo-letter shapes rather than clear text. The mask gained readable openings while drifting in overall shape; the wave had an unrequested offset; and the space emblem gained unnecessary cutouts. These observations prevent treating a higher proxy as adequate visual quality.

`semantic-structure` added transferable rules for actual readable text, coherent repeated curves, meaningful openings, and restrained contours. `graphic-economy` tested a shorter priority order for subject, composition, geometry, text, and review. Both proposals used only complete generation-zero evidence. Neither contains task answers, reference coordinates, fixed specimen counts, or stored vector geometry. The single successful second-guide trial was retained, but was not used to rank that candidate or author the third.

## Protocol and unavailable measurements

Harbor 0.18.0, Pi 0.84.2, exact GPT-6 Luna, medium reasoning, images, task bytes, verifier 1.1.0, tools, and time limits were fixed. Automatic retries were zero. The scalar objective remained **60% shape + 40% style**. It is an uncalibrated visual proxy, not an accuracy percentage or aesthetic acceptance threshold.

The preregistered rule required a qualified Pareto member with at least 0.015 mean development gain. The measured gain is smaller. The budget was three design candidates and 24 development trials, which have all been consumed. The study ends with no selected finalist and no promotion. The user-authorized local installation is explicitly experimental.

All eleven errored trials have terminal Pi events stating `WebSocket closed 1011`. Their six-case candidate fitness is null, never zero. The installed external-failure recovery workflow accepts only authoritative structured diagnostics or exact allowlisted exception types/codes. These message-only events wrapped by `RuntimeError` do not meet that contract, so no recovery trial was launched and no source result was edited to make it eligible. Exact logs and checksums are retained in the closeout.

The reserved one-way gate would compare four cases from two other families, with three attempts each for control and a frozen finalist. It requires at least 0.015 gain and no execution or format errors. It remains **unopened**; the other four reserved cases also remain unused. No private reward, output, or diagnostic informed a mutation.

A separate six-trial preliminary run is also retained. One control trial modified its copied skill, and the initial native agent declaration lacked the name expected by the analyzer. Those results were not accepted as matched quality evidence. Before final-study inference, both arms received the same explicit read-only policy and corrected agent declaration in a new frozen profile. Total native trials in this work: 6 preliminary + 24 final; no private trials and no hidden retries.

## Remaining validation and limits

Before another inference campaign, diagnose provider transport with a probe containing no benchmark task, record the repaired profile, and register a new bounded study while preserving this evidence. Do not turn unavailable trials into successes or replenish a retry cap by renaming a candidate.

Repeated naturalistic and generalization cohorts, an unforced metadata routing control, and the independent quality gate remain pending. The skill stays `validating`; structural checks alone do not release it.

All reference art comes from one vendor. The curator authored the briefs and inspected source samples before this study. A future reserved-family test is internal transfer, not independent external authorship. General prompts leave many legitimate geometric choices, so similarity to one reference cannot by itself establish that the requested drawing is correct. No guarantee of visual quality or broad superiority is claimed.
