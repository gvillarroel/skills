## Original output design

The reference-family signature is operationalized in eight separate visual dimensions: poster composition, spatial hierarchy, connection semantics, color system, typography, density/rhythm, reference-family resemblance, and fidelity/usability. Each dimension is scored 0–4 against anchored criteria in the skill's `references/evaluation.md`. These are reviewer judgments, not computed similarity percentages.

The renderer deliberately uses original synthetic data and an independent page identity. It includes a light uninterrupted diagram field, a shallow strong header, Barlow Condensed Bold titles, compact two-level labels, coherent branch colors, orthogonal connectors, explicit uncertainty/influence conventions, and source/reading notes. Partnership junctions are modeled as relationships rather than invented people. A chronology uses numeric interval positions rather than evenly spaced generations.

Barlow Condensed Bold was obtained from the [Google Fonts source repository](https://github.com/google/fonts/tree/main/ofl/barlowcondensed). Its unmodified font and SIL Open Font License are bundled, and both are embedded in exported SVGs. The source and license are retained with the skill; body type remains editable system sans serif.

## Review-driven changes

1. Separate multi-edge node ports and penalize overlapping route segments after the small starter revealed that coincident trunks could conceal colors.
2. Embed a condensed title face after the first render fell back to a wider system font.
3. Replace full-width solid timeline columns with narrow interval ribbons, visible phase boundaries, and neighboring horizontal labels.
4. Add opaque label surfaces in the timeline so grid lines do not pass through text.
5. Preserve entity IDs, budget node widths for complete words, and add automatic topological placement for ordinary lineages after isolated agents repeatedly chose unnecessarily narrow manual columns.

## Limits of the comparison

The examples are simpler and more regular than UsefulCharts' most information-dense posters. They do not validate hundreds of intermarriages, historical factual research, portraits, maps, pictograms, glyph tables, or mixed-scale histories. A good family resemblance is supported by the visible layout and connection/color decisions; identical appearance or exhaustive coverage is not claimed.
