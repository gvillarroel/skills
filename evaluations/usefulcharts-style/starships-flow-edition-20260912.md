# Star Trek full-context flow application

Date: 2026-09-12. This is an unpublished application study, not a reference-parity
pass. The prior numeric edition remains available separately.

## Result and meaning

The 6400 × 5602 SVG restores the complete original notes and source credits
beside all 79 physical spacecraft. It places 90 physical-state fragments at fixed
calendar x coordinates, using 14 shared baselines with up to seven fragments on
one baseline. Local color and bracketed family numbers distinguish 13 editorial
families; adjacency is not a lineage claim. Twenty actual routes show the
non-self relationships, with all 21 typed relationships indexed in print.

Time remains horizontal. Six explicitly labeled linear windows cover
2060–2165, 2240–2300, 2320–2360, 2360–2385, 2385–2405 and 3188–3200. Three cuts
mark omitted years. Labels may change sides through short reserved leaders;
the dated marks never shift. Seven solid spans show supported service or mission
intervals. Dashed spans show evidence endpoints; two hatched ranges retain
uncertainty. Eleven secondary fragments retain their original hull owners.

The custom application packs occupied shapes, including a long thin wake,
label block, leader and optional illustration, rather than reserving a family's
entire rectangle. It evaluates several orderings and label sides. The selected
ordering preserves family affinity instead of taking the smallest canvas.
This application prototype is separate from the isolated validation of the
bundled measured-track helper; it is not evidence that Spark authored this poster.

## Actual comparison and repairs

The official UsefulCharts world-history and denomination references were opened
and compared directly at full composition scale. They have more continuous
information fields, stronger integrated relationships and more even useful
content in their lower thirds. The current application still differs visibly.

- v1 recovered all original context but produced a tall, repetitive card field.
- v2 reduced geometry height with area-first packing but scattered family identity;
  this smaller arrangement was rejected as an editorial improvement.
- v3 introduced family affinity and routed source relationships, improving grouping
  while increasing height.
- v4 allowed measured label-side choices, preserving all date x positions.
- v5 redistributed calendar-window widths around real concurrency and added short
  annotation leaders. It remained sparse in the lower left.
- Subsequent revisions combined date wording, made secondary fragments lighter,
  differentiated family colors, retained the full notes, added local family keys,
  and changed clickable regions to their compound shapes. PDF links cover the
  label bodies, avoiding overlapping source-link rectangles.
- The first composed-background audit found four small-text contrast failures
  because routes showed through translucent label panels. Opaque dark label
  surfaces repaired these failures; the retained failure report is under
  `projects/star-trek-starships/artifacts/flow-edition/reviews/v7/`.

A generated visual study helped explore hierarchy and imagery. It contains
invented names and dates and retains full-width lanes, so it was rejected as
a final chart or factual source. Its exact prompt, references and critique are
recorded in `projects/star-trek-starships/design/composition-study.json`. None of
its invented data or spacecraft entered the source inventory.

## Verification

```powershell
uv run --script projects/star-trek-starships/scripts/build_flow_atlas.py
uv run --script projects/star-trek-starships/scripts/render_atlas.py --flow --version final --pdf
uv run --script projects/star-trek-starships/scripts/audit_space_art.py --flow
uv run --script projects/star-trek-starships/scripts/verify_flow_atlas.py
```

The independent verifier checks an evaluator-owned calendar function, complete
rendered notes and credits, source and hull identities, exact dated event kinds,
41 spans and 157 marks, all source relationships, and the actual offline viewer.
Maximum observed date-coordinate error is 0.001483 SVG units, from browser
floating-point geometry. There are no foreign occupied-shape intersections on
the 20 routed relationships. The 638 text boxes have no overlaps or clipping;
illustrations do not overlap text. Minimum actual backdrop contrast is 6.017:1.

The one-page vector PDF is 64 × 56.02 inches, has 79 independently checked source
links and three embedded font resources. The offline viewer preserves all
79 records, origin filters, 29 known and 50 unstated launch/build/commission
dates, searches across later states, related-ship navigation and responsive fit.

The initial independent verifier attempt failed because it imported a text helper
through a module with an undeclared Pillow dependency. Replacing that import with
its small Unicode-normalization function repaired the verifier without changing
the artifact. This was an evaluator dependency error, not an artifact pass.

## Remaining acceptance gap

The lower-left and lower-right areas are still unevenly occupied, and the
composition remains more like a field of annotated cards than the integrated
reference. The full semantic reference census is incomplete. Restoring all source
notes improves the displayed information inventory; it does not prove the
reference's minimum density per area, spatial distribution or aesthetic quality.
Do not call this indistinguishable, release the entire skill as done, or substitute
these technical passes for the outstanding visual judgment.
