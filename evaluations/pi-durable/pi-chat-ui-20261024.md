## Functional acceptance

Project and independently generated full consoles pass `npm run check` and
59/59 tests: 19 client, 15 command/tool, 12 public-data and 13 component cases.
The component tests use Pi's real Editor and Markdown with an in-memory
terminal. They verify Unicode/long-code/table wrapping, row/column limits,
cursor/IME focus, multiline/whitespace fidelity, scrolling, drafts while busy,
same-request retry/resume, late completions and local-only cancellation.

The host admits a stable request before waiting and saves its receipt
immediately. While waiting, bounded snapshot polling exposes only text and
bounded tool names from that submission's active run. Another run's partial
text, thinking, tool arguments and raw results remain hidden. Closing aborts
only local requests. Reopening reconciles an already terminal submission with
fresh durable history so its final reply appears once. Draft and recovery
memory are local to the current Pi session.
