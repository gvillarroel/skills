# Slidev HyperFrames integration acceptance contract

This evaluator-owned contract covers a local HyperFrames composition embedded in slidev-echarts and slidev-animejs. It qualifies actual player and iframe behavior independently of author reviews or host timestamps. The integration remains usable with only the evaluated skill and normal local tools; acceptance examples and sibling skills are excluded from isolated authoring.

## Artifact and authoring surface

Each forward case creates an editable three-slide deck and these exact nonempty paths: `deck/slides.md`, `deck/package.json`, `deck/components/HyperframeStory.vue`, `deck/data/hyperframes-story.json`, `deck/components/HyperframeSlide.vue`, `deck/lib/hyperframes.js`, `deck/public/hyperframes/starter.html`, `deck/public/hyperframes/scene.js`, and `deliverables/hyperframes-review.md`. Additional copied local assets and supporting files are allowed. Copy the whole required player/starter pack; its reusable component, bridge, local runtime and starter resources remain unchanged. Keep story data and the small deck adapter editable outside the copied skill. The package declares Slidev, Vue, the selected theme, and the pinned player runtime required by the skill.

The three slides show a large live composition, the same composition inside a configurable two-cell layout beside a concise explanation, and a deterministic export view. Cue times are 0, 4 and 9 seconds, applied through two real Slidev clicks on each live slide. Export time is 9 seconds. A Play animation/Pause animation control provides an optional preview. Leaving a slide stops hidden playback; returning applies its selected cue deterministically. Use colorset1, its maximum black/white contrast choices, and Open Sans inside the composition as well as the host deck. Assets and fonts resolve locally. Declare package scripts `build` for production HTTP output and `build:html` for a self-contained direct-open file at `deck/dist/slidev.html`. The author does not install dependencies or build; the evaluator installs exactly the submitted package dependencies in a disposable deck copy, without adding missing dependencies or repairing source, and runs those scripts.

## Independent native qualification

Build the submitted deck from its unchanged authored sources. Open its actual production output and inspect live frames after readiness, including `document.fonts.ready`, the requested cues and actual painted state. Require a successful local composition load without CDN recovery. Exact copied-resource SHA checks and the independent build gate supplement, rather than replace, native behavior.

- Forward/back navigation: use actual ArrowRight/ArrowLeft controls, verify two clicks stay on the live slide, and inspect numeric scene readouts plus nontrivial painted geometry at each cue. Later cues must produce actual changed composition state. Returning backward must recover the same readouts and geometry within a documented numerical tolerance. Wrapper `data-time` alone is insufficient.
- Preview/lifecycle: start preview with the named public control and observe genuine timeline/paint progression. Move to the next slide, retain or observe disposal of the old frame, wait, and require its hidden state to remain stable. Return and require a deterministic selected cue with no duplicate player or leaked listeners. Check no unexpected browser errors.
- Container geometry: qualify both a large slide and the live cell, then resize the actual available layout container to 680 CSS pixels and restore it. Player/frame bounds remain within the live cell and slide viewport. Readouts and labels remain complete, readable and unclipped; no dynamic font shrinking or clipped overflow is accepted.
- Style continuity: inspect computed paint and text inside the iframe, not only host chrome. Visible semantic fills use exact colorset1 tokens; opaque text uses the maximum black/white contrast against its actual backing. Verify computed Open Sans and a loaded local Open Sans face. Inspect static SVG paint/font continuity too. Existing composition-owned styles outside the supplied starter are preserved by the integration API; these cases select the bundled styled starter.
- Export: at 9 seconds, the HTTP static/seek view matches the live 9-second state. The exported direct-open HTML view at `deck/dist/slidev.html` may use the documented deterministic SVG fallback instead of a relative iframe load. It must display the correct accessible still and no loading/error placeholder. Verify an actually loaded local or inline Open Sans face in the file-protocol document, rather than relying on its computed family name. Record HTTP and file protocol behavior separately. No running timeline is required for a file-protocol fallback.
- Repeated entry and reduced motion: revisit live slides and compare cue states; a reduced-motion browser preference preserves selected content, palette, fonts and deterministic seeking. Optional continuous preview may be reduced or disabled if documented, while leaving a slide still stops all running work.

Manually inspect captured hero, cell and export slides for readability, spacing, complete labels, meaningful cell composition and palette continuity. Record actual font sizes and lifecycle observations. Do not introduce an undeclared exhaustive font whitelist or hidden animation-state requirement.

## Isolated release policy

For each changed skill, run one passing contract-smoke case and three fresh naturalistic repetitions. At least two of the three naturalistic runs must pass all applicable strict, native and manual gates. Keep every attempted run, including workflow errors and provider failures; do not reroll failed author outputs or waive strict errors because the deck later appears correct.

Use the runtime payload, strict JSON events, all exact expected paths, prompt-first read, the requested observed model, zero tool errors, a clean local runtime read surface and an unchanged copied skill payload. Attempt Spark for each skill first. If the provider rejects it before tools, retain the failure and use only the explicitly recorded model exception approved for this scoped cohort. Classify provider failures separately from author workflow, artifact, validator and infrastructure defects. Freeze prompts, the independent grader and candidate hashes before the acceptance cohort; changes require an explicitly retained new epoch.
