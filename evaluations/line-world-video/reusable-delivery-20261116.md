## New reusable operations

`project_delivery.py` promotes repeated assembly and packaging from private
example scripts into the self-contained primary skill. Its compact
`references/project-delivery.md` selects the smallest revision and routes to
the existing semantic editor, image cache, item/focus audits and whole-film
review instead of rereading large implementations or rewriting a video.

| Command | Observable behavior |
| --- | --- |
| `prepare` | Read ordered story and observed narration extents, verify actual clip frames and write a small portable request with explicit voice provenance. |
| `assemble` | Hash inputs, preserve measured audio partitions, reject insufficient visual budgets, stream-copy compatible H.264 clips, preserve every nonzero short container tail with a final reading hold, fully decode the result and replace outputs atomically. |
| `bundle` | Include the actual reference/clip inputs, explicit optional owned sources, the standalone utility, rebuild entry point and digest manifest; verify ZIP contents and keep each archive path immutable. |

Matching digests reuse actual output bytes without media commands. Cache
receipts now persist `reused: true`, so compact stdout and saved JSON agree.
Archive membership participates in cache identity: renaming an equal-byte
optional source invalidates the prior bundle. Outputs cannot overwrite inputs,
paths cannot traverse outside the project, and failures preserve the prior
owned output. Recorded provenance is caller-supplied evidence, not independent
provider verification. Local output always declares `nativeGoogleVidsExport:
false`; packaging/reassembly is not a claim that a source renderer or native
cloud project was rebuilt.

The repository guide now documents build/install, the operation table and
conditional references. `prepare_publication.py` copies an explicit Line World
scope into a separate project-owned worktree and merges only the two backlog
rows, one documentation index link and two color-inventory entries. It excludes
generated media/cache/history and preserves unrelated local changes. This
project-maintenance helper is not a runtime dependency of the skill.

The `Build Line World plugin` workflow builds actual installable ZIPs on relevant
main-branch changes, tests the new deterministic media utility and uploads a
versioned artifact with both packages and a digest receipt, retained for 30 days.
It does not synthesize speech, access accounts or install global host settings.
