# Repository plugin marketplace: November 16, 2026

The source registry is `projects/skills-marketplace/catalog.json`. It initially
contains Line World Video and the maintained HyperFrames plugin. Generated
native and compatibility catalogs and complete plugin directories are
published on the `marketplace` branch of the same repository. Authoring inputs
remain on `main`; ignored local installations are not canonical sources.

Five regression tests pass:

```powershell
uv run --script projects/skills-marketplace/scripts/test_marketplace.py
```

The fixtures use real temporary Git repositories under ignored project
artifacts. They verify committed-snapshot isolation from dirty inputs,
idempotent reuse, complete inventory/digest checks, valid native relative
paths, duplicate and escaping source rejection, tracked native identity for
new entries, ordinary fast-forward publication, immutable same-version plugin
payloads and preservation of authored files and dirty checkout changes.

The release workflow builds from committed Git bytes, checks every managed
file, installs both plugins with Codex 0.167.0 in a task-local home, requires
app-server discovery of every installed skill and publishes without force.
Native installation and discovery use zero model turns. A separate verifier
accepts a remote `owner/repo` and Git reference so the published installation
can be checked independently of the local build directory. Receipts stay in
project artifacts and the workflow artifact; no personal configuration or
account credentials are distributed. Backend loader checks do not claim
desktop UI paint or Google account authorization.

Installation and future-plugin authoring commands are maintained in
[the marketplace guide](../../docs/plugins-marketplace.md).
