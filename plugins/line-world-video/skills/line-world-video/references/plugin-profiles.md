# Dedicated producer copies

The plugin is a coordinated video toolset. Its specialized producer skills are
materialized from the current general D3, Mermaid, Iconify and HyperFrames
Explainer runtime bundles. Keep the general canonical sources intact; apply
video changes only to the distributable copies.

bundle contains its own instructions, shared contract and original runtime.
General human-readable galleries and document guidance are omitted from these
copies. Each has a compact producer-operations reference for needed syntax and
export details; original executable resources remain available in the copy.

## Default decisions

Use simple geometry, white surfaces, neutral strokes, red focus and a single
seekable parent clock. Omit unrequested titles, subtitle bands, chapter badges,
closing slogans, promotional cards, decorative gradients, drop shadows, stock
embellishments and standalone preview chrome. Preserve actual data marks,
essential legends, units, notation and useful entity labels.

Give red the leading role and light/medium grays the secondary role. Keep
charcoal for text and fine detail; reserve black for a last contrast need.
Every materialized copy receives the private red/gray-first palette and records
its hash. Avoid large dark neutral fills, including imported quantitative bands.

Partition the complete frame, put margins inside sections, choose complementary
views, connect stable entity IDs and budget reading time. Expose pure time-based
state rather than independent producer playback. Use colorset2 only for a
documented category distinction.

## Materialization and verification

Record original skill name, source digest, profile digest, shared-contract
digest and any executable patch in each copied skill's `video-profile.json`.
The Mermaid renderer patch must replace exactly one known import/call site;
fail clearly on upstream drift. Its native video finish preserves quantitative
geometry, removes automatic diagram headings and gives CS1 items borderless
gray/red surfaces while retaining white outlined groups. It leaves contextual
words to the parent story.

Validate each materialized skill bundle, check profile names and runtime
resources, execute the patched Mermaid renderer against real source, inspect
rendered style and metadata, and perform an isolated integration test. Keep
these checks separate from standalone orchestrator forward tests. Do not claim
that copied producers were individually release-tested unless their runs exist.
